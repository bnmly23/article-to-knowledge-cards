# make-knowledge-cards

把一个粘贴的文章或本地 Markdown/TXT 文件，整理成一组「知识卡片」，方便快速复习和掌握重点。

## 项目解决什么问题

读长文章时，自己提炼笔记既费时又容易抓不住重点，还可能不自觉地把原文没有的内容加进去，或者为了凑张数而重复拆分。make-knowledge-cards 把这件事交给 Agent：从原文里挑出真正重要的知识点，按「一张卡片一个知识点」的格式输出，并且保证不编造、不重复、信息不足时不硬凑数量。

## 主要功能

- 从文章中提取真正重要的知识（定义、原理/机制、规则/原则、关键事实、步骤流程、对比与结论）
- 每张卡片只讲一个知识点，固定包含四个字段：标题、核心知识、简明解释、例子或自测问题
- 删除重复内容，卡片之间不重复
- 不编造原文没有的信息，例子优先取自原文
- 卡片数量跟随内容：典型文章 5~8 张，信息不足时不会强行凑数
- 支持粘贴的文本和本地 `.md` / `.txt` 文件，输出语言跟随用户

暂不支持：网页抓取、PDF、Anki 导出、图形界面。

## 安装方法

这是一个遵循 [open agent skills](https://agentskills.io/) 标准的 Agent Skill，无需构建、无需安装依赖，只需把 `skills/make-knowledge-cards/` 目录复制到对应工具的技能目录即可：

- **Claude Code**：复制到用户级 `~/.claude/skills/`，或项目内的 `.claude/skills/`
- **Cherry Studio**：复制到其技能目录（`$CHERRY_STUDIO_SKILLS_DIR`），应用会自动同步
- **其他支持 open agent skills 的 Agent**（Codex、ChatGPT 等）：复制到各自的技能目录

## 使用方法

直接用自然语言请求即可，例如：

- 「把下面这篇文章整理成知识卡片：……」
- 「把 notes.md 转成知识卡片」
- 「帮我提炼这篇文章的要点，做成学习卡片」

也可以给出本地 `.md` / `.txt` 文件路径，技能会读取该文件。

## 输入输出示例

**输入：**

> 光合作用是植物利用光能把二氧化碳和水转化为有机物并释放氧气的过程。它主要发生在叶绿体中。叶绿素负责吸收光能。光合作用为地球上几乎所有生命提供了能量和氧气。

**输出：**

```markdown
## 知识卡片

### 卡片 1：光合作用是什么
- **核心知识**：光合作用是植物利用光能把二氧化碳和水转化为有机物并释放氧气的过程。
- **简明解释**：植物用「光」当能源，把简单的原料变成养分，同时放出氧气。
- **例子 / 自测**：自测——光合作用把哪两种原料转化成了什么产物？

### 卡片 2：光合作用发生在叶绿体
- **核心知识**：光合作用主要发生在叶绿体中。
- **简明解释**：叶绿体是细胞里负责这项工作的「车间」。
- **例子 / 自测**：自测——光合作用主要在细胞的哪个结构里进行？

### 卡片 3：叶绿素吸收光能
- **核心知识**：叶绿素负责吸收光能。
- **简明解释**：叶绿素是吸收光能的关键色素，没有它光能就进不来。
- **例子 / 自测**：自测——负责吸收光能的色素叫什么？
```

> 原文信息有限，只出了 3 张，而不是硬凑 5~8 张。
