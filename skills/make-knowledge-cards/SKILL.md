# Make Knowledge Cards（知识卡片）

把一篇用户提供的文章（粘贴的文本，或本地 Markdown/TXT 文件）转换成一组「知识卡片」，帮助用户快速复习并掌握原文中真正重要的内容。

## 你能处理什么

- ✅ 用户直接粘贴的文章文本
- ✅ 本地 `.md` 或 `.txt` 文件（用户给出路径时，读取该文件）
- ❌ 网页抓取 / URL 转卡片：不要主动联网抓取；如果用户给的是链接，请对方粘贴正文，或存成 .md/.txt 再给你
- ❌ PDF、Word 等其他格式
- ❌ Anki / APKG 导出
- ❌ 图形界面（本技能是「文本进、文本出」）

## 卡片格式

每张卡片只讲一个知识点，固定包含四个字段：

1. **标题**：用陈述句或名词短语点出这一个知识点，不要用问句当标题
2. **核心知识**：用 1~2 句话准确陈述这个知识点本身
3. **简明解释**：用更通俗的话重述，说明它为什么重要、该怎么理解
4. **例子或自测问题**：一个例子（优先取自原文），或一个自测问题；自测必须能仅凭这张卡片回答

## 工作流程

1. **读取原文**
   - 用户粘贴了文本 → 直接用
   - 用户给了 `.md` / `.txt` 路径 → 读取该文件
   - 其他格式或链接 → 明确告知暂不支持，并说明可以怎么提供原文（粘贴或存成 md/txt），不要硬凑

2. **挑出真正重要的知识**
   优先保留：定义、原理/机制/原因、规则/原则、关键事实或数字、步骤流程、对比与结论。
   忽略：与核心无关的铺垫、没有结论的轶事、重复的措辞、套话与客套。

3. **一张卡片只讲一个点**
   - 复合观点 → 拆成多张卡片
   - 相近或重复的观点 → 合并成一张
   - 删掉所有重复内容，卡片之间不重复

4. **只写原文有的信息，绝不编造**
   - 不添加原文没有的事实、数字、人名、日期、出处
   - 例子优先取自原文；原文没有例子时，改写成自测问题，而不是凭空编一个例子
   - 拿不准时宁可写得保守

5. **卡片数量跟着内容走，而不是反着来**
   - 典型文章目标 5~8 张
   - 原文信息不足（例如只有 3 个独立观点）就只出 3 张，不要为了凑数而拆分、重复或硬凑
   - 原文高质量观点超过 8 个时，挑最重要的 8 个

## 输出格式

默认输出 Markdown，语言跟随用户（用户用中文就输出中文，用英文就输出英文）：

```markdown
## 知识卡片

### 卡片 1：<标题>
- **核心知识**：...
- **简明解释**：...
- **例子 / 自测**：...

### 卡片 2：<标题>
- **核心知识**：...
- **简明解释**：...
- **例子 / 自测**：...
```

输出只写进回复，不要修改或删除用户的输入文件。

## 示例

**输入（简化的原文）：**

光合作用是植物利用光能把二氧化碳和水转化为有机物并释放氧气的过程。它主要发生在叶绿体中。叶绿素负责吸收光能。光合作用为地球上几乎所有生命提供了能量和氧气。

**输出（原文信息有限，只出 3 张，不凑数）：**

### 卡片 1：光合作用是什么
- **核心知识**：光合作用是植物利用光能把二氧化碳和水转化为有机物并释放氧气的过程。
- **简明解释**：植物用「光」当能源，把简单的原料变成养分，同时放出氧气。
- **例子 / 自测**：自测——光合作用把哪两种原料转化成了什么产物？

### 卡片 2：光合作用发生在叶绿体
- **核心知识**：光合作用主要发生在叶绿体中。
- **简明解释**：叶绿体是细胞里负责这项工作的「车间」。
- **例子 / 自测**：自测——光合作用主要在细胞的哪个结构里进行？

### 卡片 3：叶绿素吸收光能
- **核心知识**：叶绿素负责吸收光能。
- **简明解释**：叶绿素是吸收光能的关键色素，没有它光能就进不来。
- **例子 / 自测**：自测——负责吸收光能的色素叫什么？
